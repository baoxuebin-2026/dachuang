# 多设备混合气 CO 标定：截至 2026-10-20 的探索记录

本目录保存纯气体路线的实验协议、逐次配气特征、Python 脚本和输出。研究问题是：用少量目标设备的已知 CO 配方做残差校正后，如何比较两种源训练范围，并在证据不足时暂缓选择。焦化园区是应用动机，本实验数据来自公开的受控混合气研究。**所有目标设备结果都已在探索过程中查看；这不是独立盲测，也不是原创性或投稿录用的证明。**

完整数据边界、结果、反例及文献比较见 [`../../docs/gas-source-selection-exploration-2026-10-20.md`](../../docs/gas-source-selection-exploration-2026-10-20.md)。本目录另附各阶段预先记录的中文协议，不能把事后提出的规则称为事前冻结。

## 数据与可复现范围

| 原始数据 | 官方来源 | 本目录的提取文件 | 说明 |
|---|---|---|---|
| 三设备同步混合气 | [Zenodo 6821340](https://doi.org/10.5281/zenodo.6821340) | `exposures_6821340.npz` | 官方训练、测试划分；同一配方的三只设备不能当成三次独立配气 |
| 双传感器多批次混合气 | [Zenodo 4264224](https://doi.org/10.5281/zenodo.4264224) | `exposures_4264224.npz` | 批次与传感器之间的重复结构须保留 |
| 两传感器跨标定期 | [Zenodo 4593853](https://doi.org/10.5281/zenodo.4593853) | `exposures_4593853.npz` | 多次读数聚合到一次配气 |
| 七设备随机混合气 | [Zenodo 15423482](https://doi.org/10.5281/zenodo.15423482) | `exposures_15423482_first.npz` | 仅首次标定有 CO 标签 |

`.npz` 是按原始独立配气聚合的分析特征，非全部原始数据；每份 `exposure_extraction_*.json` 记录字段、数量及来源。原始 MAT 文件未随仓库上传。要重新提取特征，请先从上述 DOI 下载原文件，核对 JSON/脚本里的 MD5 和文件名，再在**本目录**执行 `extract_*.py`。当前脚本使用相对于工作目录的文件名。

已经提取好特征时，在本目录安装 `numpy scipy scikit-learn h5py`，即可运行相应分析脚本，例如：

```bash
python source_selection_abstention_6821340.py
python source_gate_external_4264224.py
python seven_device_source_gate_15423482.py
```

各 `*_results.json` 为本轮探索记录。重新运行会覆盖同名 JSON；先复制目录可保留原记录。具体固定抽样、模型、阈值与各项失败的判据见协议及脚本，不要把 50 个重复选样种子解释为 50 个新设备或独立测试。

## 当前判断

增加强干扰源数据在 B、C 设备上导致相反方向的误差变化；20 次目标配方校正后，C 的源模型排序出现反转。基于标定配方的配对留一误差，只有差值超过 2 倍标准误才选择，否则暂缓，是**探索后形成的工程候选**。在另两套数据上做过压力测试，但结果都已暴露，且七设备实验只覆盖“全范围源占优”一侧。下一步应寻找尚未查看标签的多设备 CO 混合气数据并事前锁定规则；失败时应报告负迁移与选源困难，不继续事后调整门槛来制造盲测结论。
