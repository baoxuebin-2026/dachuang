# METEC 辅助分析协议候选：按日期留一的固定阈值诊断

拟定日期：2026-09-27（北京时间）。项目组已选择“METEC 只作辅助证据，不继续下载大文件”。本页把该决定转成可执行协议；候选配置见 [`stage9_metec_aux_protocol_candidate_v1.json`](../configs/stage9_metec_aux_protocol_candidate_v1.json)。**协议尚未批准，未运行新实验，也没有新增模型成绩。**

## 1. 研究问题

在具有独立释放起止记录、但甲烷观测高度间断的 METEC 数据中，只用单点干甲烷浓度时，训练日期的无记录释放背景所确定的固定阈值，能否在未参与定阈值的日期中稳定区分“全场有活动释放”和“无记录释放”观测秒？

它检验的是**受控场地释放状态与单点浓度的关联稳定性**，不是事故发生前预测、完整事件检测或焦化园区现场预警。

## 2. 为什么不训练 AI 模型

当前文件只有甲烷浓度和分析仪内部气体压力、气体温度、采样频率。压力和温度不是焦化园区环境温湿度；释放点距离、风向和场地障碍对测点是否截获羽流很关键，但本轮没有下载同期气象流。用 XGBoost、LSTM 或 Transformer只会在稀疏秒级片段上学习日期、仪器状态或释放占比，不能补出缺失的连续事件窗口。

因此本轮将“是否需要复杂模型”本身作为结论的一部分：先用可解释固定阈值和跨日期稳定性检查。如果简单方法不稳定，正确结论是单点浓度不足，而不是继续堆模型。

## 3. 冻结的数据单位和标签

- 同一整数秒内的 `x_CH4_d_ppm` 取中位数，作为一条观测。
- 释放表中任一释放点处于 `UTCStart ≤ t < UTCEnd` 时，该秒记为 `release_active=1`；否则记为0。
- 主时区解释为固定 MST（UTC−7）；`America/Denver` 夏令时解释只作敏感性复算。
- 本地日期是独立分组单位。秒级观测只用于算日期内部比例和排序，不被当成数十万个独立事故。
- 日期至少需要30个释放观测秒和30个无记录释放观测秒；按已完成审计预计有43个可评价日期。2024-03-22只有28个释放秒且无阴性，不进入主评价。

## 4. 候选方法

### P1：按日期留一的全局背景 P95（推荐主协议）

每轮留出一个完整日期，只用其余日期的 `release_active=0` 秒确定干甲烷 P95 阈值，再原样应用到留出日。记录留出日释放秒超阈值比例、非释放秒超阈值比例和浓度排序 AUC。遍历全部合格日期，最后按日期等权汇总中位数和四分位距。

P99 仅作为预先固定的低触发敏感性点，不在看完留出结果后改为主阈值。阈值绝不使用留出日数据，也不按当天结果回调。

优点：最容易复核，能直接显示跨日期漂移和固定阈值代价；没有模型超参数。缺点：它仍按观测秒评价，无法变成事件检出率或误报次数／小时。

### P2：增加“当天背景已知”的理想校准上界

利用留出日真实的无记录释放秒估计当天背景，再计算日内归一化阈值表现。这会使用发布后的释放日志挑选背景，现实部署时并不知道这些标签，只能称为**离线理想校准上界**。

优点：能估计日间背景漂移得到校准后理论上可改善多少。缺点：容易被误写成可部署算法，并且使用测试日标签；不适合作主结果。

### P3：训练逻辑回归／树模型

按日期留一训练分类器，把甲烷、仪器内部压力和温度作为输入。

优点：形式上具有机器学习对照。缺点：内部气体状态不是园区环境变量，缺少气象、距离和风向；模型可能学习仪器或日期差异，解释性和迁移价值更差。**不推荐执行。**

## 5. 评价与不确定性

主表逐日期列出观测量、训练背景阈值、释放秒超阈值比例、非释放秒超阈值比例和 AUC；汇总采用日期等权的中位数、四分位距。95%区间只通过对日期整组重采样5000次获得，固定随机种子 `20260927`；不对相关的秒级样本套普通二项置信区间。

同时必须给出：

1. 固定 MST 与夏令时解释的结果差异；
2. P95 与 P99 的触发覆盖权衡；
3. 每个日期的散点或区间图，避免只报一个好看的合并平均数；
4. 对最大、最小 AUC 日期的原始分布复核，但不据此删除日期或修改阈值。

## 6. 禁止输出

本协议不输出“每小时误报”“完整事件检出率”“泄漏提前量”“焦化现场准确率”或“四级事故预警准确率”。也不把 METEC 与 Bonn 时间戳拼接，不声称 D435、Jetson 或现场传感器参与实验。

## 7. 推荐与决策门

推荐批准 **P1**，P99和时区解释只作预先固定敏感性；不执行P2、P3。这样可以用最少工作量证明两件事：独立释放日志下确有甲烷响应，以及单点固定阈值跨日期并不稳定。它对论文的作用是加强证据边界和模型选择理由，而不是再制造一条虚假的高准确率主线。

批准后才实现运行脚本、单元测试、逐日期CSV、汇总JSON和一张跨日期图。任何结果都保留，不因表现差而换阈值或删日期。
