# T1-A 正文第 2 节工作稿：研究问题与数据来源

日期：2026-09-26（北京时间）。**只起草已获项目组确认的 T1-A 路线中的这一节，不是完整论文或已投稿版本。**数据描述和实验结果分别核对；本文拟用的“焦化园区”是方法应用情境，本文没有焦化厂现场记录。

## 2.1 研究对象与可验证问题

申报方案的预警链路需要气体变化证据、人员空间证据和跨源处置规则。受现有数据条件限制，本研究将其拆为三个分别可验证的对象：（1）受控风洞中，传感器阵列对释放后气体变化的响应检出；（2）室内 RGB-D 序列中，人员二维框、深度可用性判定与相机坐标下的虚拟区域计算；（3）给定实验气体证据和明确标记的模拟人员路径时，分级处置规则对同区、异区、缺测及证据过期的输出行为。第三项只检验预先定义的规则能否按设定运行，不以规则输出作为独立事故真值。

本节采用三个不同的观察单位：完整气体实验文件、抽样 RGB-D 帧和重复使用气体文件的仿真重放。不同来源的时间戳、地点、相机坐标和气体覆盖区域没有共同标定；不能将不同数据集按时间拼接并计算“融合准确率”。研究内 `unknown` 表示证据不足或不满足配对条件，不能改记为安全；L0—L3 表示仿真处置优先级，尚不对应法规风险等级或事故后果。

## 2.2 数据来源与使用边界

| 数据来源 | 已有数据与分析单位 | 本文用途及参照 | 不具备的真值 |
| --- | --- | --- | --- |
| [UCI 309 气体传感阵列风洞试验](https://archive.ics.uci.edu/dataset/309/gas+sensor+array+exposed+to+turbulent+gas+mixtures.) | 180 个完整试验文件；按文件分训练 90、验证 30、留出 60；8 路气体传感器及温湿度。每次试验程序于 60 s 开始供气，240 s 停止。 | 以供气程序时刻作**离线**释放后检测参照，报告文件级检出及短暂释放前背景触发；GC-MS 是平均浓度测量。 | 无逐秒空间浓度、长期纯阴性、人员暴露或事故发生前的独立真值。 |
| [Bonn RGB-D Dynamic Dataset](https://www.ipb.uni-bonn.de/data/rgbd-dynamic-dataset/) 两段 `person_tracking` | 室内两段相似序列，从 RGB 图像固定抽样 58＋57＝115 帧，团队人工标出 66 个人员二维框，并用配对深度图计算相机相对位置；24 帧另有复标。 | 检验预先选定人员检测器与 A1 深度门控、G1 相机横向虚拟区域的软件接口。人工框只是二维检测参照。 | 无独立人员三维位置或真实禁区真值；相机位姿真值不能替代人员位置真值；数据不是 D435 或焦化园区视频。 |
| S1 场景重放 | 重用 UCI 309 **同一批 60 个**留出文件，给各文件施加同一套模拟人员轨迹、区域归属、时钟及故障反例。 | 检查规则对气体状态、模拟人员状态及证据质量的条件处置行为。 | 无真实同期人员、气体空间分布和独立事故等级。60 次重放不等于 60 起真实联合事件。 |

UCI 309 的秒级处理仅把每个 `[n,n+1)` s 窗口内重复时间戳读数压缩为中位数，在 `n+1` 时刻输出；使用试验初期 `[5,25)` s 的已知清洁段校准，因此结果依赖有清洁启动的条件。固定 60 s 供气程序会产生时间捷径风险，不能把“供气后若干秒检测到响应”写作事故发生前预警。原留出集在离线评分修订后已重复查看，故本文报告探索性留出评价，而不声称全新盲测。[具体协议与结果](stage5-m1-pilot-results.md)。

Bonn 的深度 PNG 与 RGB 图按原始时间戳配对；人员框由项目组给出，不是公开数据自带的人员真值。两份最终人工标签在 2026-09-26 已按原冻结 SHA-256 恢复；固定检测器和 A1／G1 规则用相同两段室内序列[重跑复核](stage9-bonn-rerun-20260926.md)。第二段此前已经用于标注质检，属于相似室内条件的复核，不能据此推断跨园区泛化。G1 的横向虚拟区采用相机光学坐标的 `X`；S1 的 `P` 状态来自另一套**模拟地面矩形区**，二者没有坐标变换或同步采样证据，因此 Bonn 的 G1 分类没有被当作 S1 的真实人员输入。[接口界限](stage8-n1-system-evidence-map.md)。

## 2.3 补充证据及出处标识

UCI 322 为动态气室中的乙烯＋CO、乙烯＋甲烷两组实验，气体字段为供气设定值；已有结果只作为泛气体响应和乙烯干扰诊断。UCI 487 来自另一套 CO 暴露实验，其跨实验日、留出段位的已完成暴露段校准不代表实时泄漏预警。SB112 为一台楼宇传感器的背景日记录，缺乏逐秒事故阴性真值。这三组数据只作**独立补充**，不与 309 或 Bonn 拼成一条同址同钟轨迹。[证据表](stage9-manuscript-evidence-table-v0.md)。

原申报的 D435、气体／温湿度／粉尘／液位传感器和 Jetson Orin Nano 仅用于**拟部署系统接口**的讨论。本文没有使用这些具体设备采集或测试；烟雾遮挡、积液、车辆和人员操作违规等原定功能尚无对应实验证据。完整论文在方法和讨论节继续逐项对照这些未完成内容，不能用设备架构图替代实验。
