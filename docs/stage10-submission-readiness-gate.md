## 当前判断

现有数据已经足以支撑一篇**有限范围的方法论文**，无需为了凑申报场景继续寻找数据。气体、视觉、规则和外部阈值诊断分别有可追溯结果，S1 也已有基线及逐项去门控对照。稿件必须保持“模块化公开数据验证＋场景仿真”的定位。

[完整论文工作稿 v1](manuscript-full-v1.md)已经覆盖题目、摘要、引言、问题定义、系统架构、方法、实验结果、讨论和结论；[论文级表格](stage10-manuscript-tables-v1.md)与正式参考文献库也已存在。当前状态是**可进入导师审稿和期刊排版**，还不是可直接上传的最终稿。

## 是否需要新增数据

当前投稿准备阶段**不建议新增数据**。新增数据只有在明确补以下任一主张时才有价值：

1. 真实视觉—气体联合效果：需要同址、同钟、同区域并有独立场景真值；
2. 真实人体测距／越界精度：需要相机标定、地面区几何和人体位置参照；
3. 硬件实时性：需要 D435、现场传感器和 Jetson 实机；
4. 长期现场误报：需要足够长的事故阴性运行和事件核验。

零散再找一个公开气体数据集或增加 LSTM/Transformer 不会补齐这些主张，反而会扩大审稿人对跨数据可比性的质疑。若投稿后审稿意见明确要求其中一项，再按具体意见决定补实验或改投更匹配的方法类期刊。

## 下一执行顺序

1. 项目组和指导教师先填写作者、单位、项目编号并确认题目；
2. 按《电子测量技术》最新模板整理 Word 版、英文摘要和 GB/T 7714 参考文献；
3. 做一轮逐句主张审计和图表终稿检查；
4. 再进行投稿，不在此阶段继续扩数据范围。
