# 阶段 9：T1-A 论文证据与文献缺口核查（决策稿）

核查日期：2026-09-25。范围仅限项目组已定的 **UCI 309 气体＋Bonn 室内 RGB-D＋S1 仿真处置**正文主线；UCI 322、487、SB112 仍为各自独立的补充证据。本稿是证据审计与下一项实验的选项，**没有新增实验、完成论文正文或选定期刊**。研究对象是拟用于焦化园区的算法框架，没有焦化现场数据、D435 实采或 Jetson 实测。

## 1. 论文当前可以回答什么

在公开的受控气体试验中，固定方法能否提示传感器响应变化？在公开室内画面中，预选检测器能否提供人员框，深度门控能否给出可用的相机相对位置？给定明确声明的模拟同钟、同区及人员轨迹，规则能否按定义保留缺测并给出分级**处置输出**？三个问题可以分开检验。现有资料不能回答“焦化厂事故能提前多少时间预警”“真实人员距离是否精确”“联合预警是否比单源报警减少事故误报”。尤其不能将气体源的实验时钟和另一实验室的摄像时钟拼成同期观察。

## 4. S1 自证风险及需要改变的评价对象

S1 规则先定义 `G2` 气体证据和模拟 `P1/P2` 为 `L3`；随后给同一批文件附上人为编排的 P 轨迹，再统计是否输出 L3。设规则 `F(G,P,时空有效性)=L`，用 `F` 自身对其输出的 L 作正确性评价，等于把预设矩阵当成真值。58/60 主要反映所选气体检出与人工重叠时间的交集；0/60 错区、600 个未知秒是输入案例触发分支的结果。它们能检验实现是否遵守规格，却不能估计真实的风险等级准确率、联合优于单气体的幅度或事故减少量。

另有接口断点：Bonn G1 是 `X=(u-cx)Z/fx` 的**相机横向**虚拟区；S1 P 是模拟**地面平面**的区域/距离，并带单独虚构的时间、区域 ID。两者没有同一坐标系标定、人员足点投影和同址同钟记录；不能声称已把 Bonn 的 P 接进 S1。危险程度还需要危害物质、暴露量与真实作业区的物理依据；L0—L3 当前只是研究内部**处置级别**。

## 5. 只补一项实验时的路线比较

| 方案 | 实际工作与可测输出 | 代价、收益和保留的缺口 |
| --- | --- | --- |
| **A：不新增验证，按现有证据收窄论文** | 完成文献全文核验、摘要措辞审计、论文证据表；仅报告单模块性能与 S1 软件规则重放。 | 人力最低、结果可诚实；但“多源分级处置”的独立比较依然空缺，论文方法性贡献弱。 |
| **B：建议优先考虑，预注册独立审阅的挑战案例** | 项目成员先冻结规则与评价指标；由**未看 S1 输出的外部审阅者**给出若干既定风险说明下的处置优先级和“证据不足”标记，并由另一成员保管答案。审阅方案与模型不得共用 L 矩阵作为答案；案例覆盖乙烯单独刺激、无气体/长期阴性、人员同区/异区、时间偏移、坐标边界、传感器缺失及扰动。冻结后一次性比较 S1 与气体单源、人员单源、简单 OR/AND；报告审阅一致性、按案例计数的有条件一致率、误触发与未知率，分案例展示冲突。 | 不需购置设备，能实测“研究内处置决策是否与**独立审阅判断**相符”并发现反例。案例仍是重组/仿真、审阅也不是事故真值；当审阅者照搬 S1 矩阵、样本来自同一原轨迹、没有相对独立的领域判断时，该方案**失败**，应诚实回退 A。无法证明焦化现场有效性。 |
| **C：同期实采气体＋人员＋区域的带真值实验** | 在合规实验条件下用独立参照测量气体、同步 RGB-D、区域坐标与人员位置，并预留没有气体释放的对照；冻结算法后评估事件级提前量、错误与失配。 | 联合预警证据最强，但目前无设备、场地或授权数据；气体实验涉及安全条件，成本与排期最高，不能作为当前论文已有成果。 |

**建议 B，但先检查可行门槛：**能否找到至少一位不参与规则制定、愿意就*给定案例*独立审阅的适当专业人士；能否明确区分“人为案例的处置优先级”与“真实事故分级”；能否取得足以构造长时阴性与独立挑战的来源。既有 UCI 322 的乙烯单独刺激和 SB112 背景日只能作不同来源的反例/补充，不能被拼成同址同钟真值；若这些门槛达不到，直接走 A，不补造标签。B 的样本量、具体案例及统计方法需项目组确认路线后单独提交冻结协议，**目前不设想或报告任何新指标数值**。

## 【需要人类决策】

本节点只选择下一步投入：**A 按现有证据写作，B 尝试冻结独立审阅的挑战案例，或 C 待具备真实同期实验条件再做联合验证**。推荐 B；如果找不到独立审阅者，可选 A。期刊及预算暂不需选择；此决定不自动授权开始新实验，先提交 B 的可检验协议供确认。
