# 阶段 9 / B：独立审阅挑战案例协议（待确认，不是实验结果）

拟定日期：2026-09-25（北京时间）。项目组已从[证据缺口报告](stage9-evidence-literature-gap-audit.md)的 A/B/C 中选择 **B**。本稿把 B 变成可审查的实验协议；**尚未冻结案例、邀请审阅者、生成标签、运行新实验或修改 S1**。原定的 T1-A 论文主次不变。所有联合案例都是“UCI 实验室气体证据＋明确标注的模拟人员位置”，不产生真实现场多模态观测。

## 1. 检验对象与明确边界

**问题：**在来源、区域、时间有效性均写清的模拟决策场景里，固定 S1 处置输出与独立审阅者依据可见证据给出的**处置意见**有多一致？不一致集中在哪里？比只看单路证据或简易合取/析取规则多保留了哪些信息？审阅意见是人为案例评价，不是事故发生、人员暴露或四级真实风险标签。

**分开的三个观察对象：**

1. 主组：UCI 309 同一实验室的原始八路传感器流，配独立生成、明示为模拟的人员区域状态；能比较模拟场景下的处置意见。
2. 附加干扰组：UCI 322 的乙烯单独刺激、乙烯＋目标气体等**另一套气室传感器**；只核对已有 B1 的泛气体响应与物质不可区分问题，不能把 309 阈值直接接到 322 上，也不能合并报告主组的一致率。
3. Bonn 人员框与深度依然是单独的视觉可用性实验；其相机横向 G1 区域没有映射到 S1 地面矩形。**不得**把 Bonn 录像与主组案例写成同步采样。

## 3. 候选主组：24 个独立案例，不以报警结果挑选

| 案例族 | 例数 | 候选来源和设计目的 |
| --- | ---: | --- |
| 释放前且人员远离 | 4 | 309 的预释放洁净时段；评估过度升级，不等同全天阴性 |
| 释放前且人员位于假定控制区内/缓冲 | 4 | 人员单路与气体单路分开；不把“区域内”自动等同气体暴露 |
| 实验供气开启后，人员远离 | 4 | 气体单路持续变化仍有处置价值；禁止凭空生成“人受害” |
| 实验供气开启后，人员靠近或在区内 | 4 | 条件联合处置；讨论区内是**假定覆盖**，不是测得气云 |
| **仅乙烯**供气且人员靠近 | 4 | 309 文件名第二气体 `CO_n/Me_n`；检验“泛气体变化＝CO/CH4 危险”这种误写。若仅给审阅者传感器流而不给物质真值，只能询问“应否核验物质”，不能把其未知气种判断记作错 |
| 失配/缺测/边界不确定 | 4 | 明示仿真的时钟过期、异区或缺测，并至少有一例接近模拟边界；审阅者可以选证据不足 |

**取样候选规则：**每例对应一个**不同**的 309 留出文件；从现有 60 个 test ID 的所需气种层按 `SHA-256(预先固定的 seed || trial_id || 案例族)` 排序选取，并保存 24 个 ID 及不可替换的候补顺序。先按气种/释放程序和案例族条件选样，再运行 S1；禁止看检测分数、首检时刻、L3 或审阅意见后换样。需要的 CO/甲烷有效供气各 24 个、仅乙烯 12 个 test 文件已按[清单](../results/m1_uci309/split_manifest.csv)初核；其余类别可取不同文件，**不得让某一文件出现两例再冒充独立实验**。按文件名选择气体程序只能用来**离线分层**，不得输入警报算法。

**窗口与人员生成规则草案：**每例只供审阅固定的 10 秒判读窗口，并给出其前 30 秒传感器上下文；释放前窗口 `[40,50)` 秒，释放后窗口 `[120,130)` 秒，均在已有 S1 的 `[26,240]` 秒范围。时间窗按实验程序预定，与文件首个 G2 时刻无关；不为凑到 L3 调整。人员点在旧模拟 `zone_A=[0,2]×[0,2] m` 内、缓冲内、远离及边界附近的**明确坐标**由单独的固定种子生成，在所有算法运行之前保存；位置源统一标记 `simulation`。用于失配类的过期量与 `zone_B` 故障参照[既定 S1 配置](../configs/stage6_s1_fixed_a.json)，改变的具体秒数须写入后续冻结配置。10 秒窗口是一个审阅单位，不把其中的每秒当成独立样本；如评价需要前 30 秒气体上下文，算法侧使用的初始化和历史长度也须事先记录。

**失衡风险：**人为令六族各 4 例仅为覆盖极端情形；病例比例**不是园区事件发生率**。固定 60 s 释放程序仍可能给实验者提供时钟捷径，因此不报告事件前预测、绝对准确率或可推算到日的误报率。309 test 已在此前多次被查看；新案例与审阅仅能称**新增盲审内容**，不能称模型对 309 的全新盲测。

## 4. 审阅材料、盲法和表单

由不参与审阅的项目成员生成随机 `case_id`。给每位审阅者同一份短说明：单位和传感器性质、模拟矩形区/1 m 缓冲的**人为设定**、10 秒窗口及前史、是否同一假定区、测量延迟/缺测标记、人员点的模拟来源。气体图展示相同缩放规则下的原始八通道变化和温湿度，不展示 M1 得分、G0/G1/G2、S1 的 L0—L3、旧 S1 矩阵、文件名中的气体组合和模型输出；保留原始气体文件名/实验供气方案于审计底稿，报告时揭示。审阅者的全部判断只能依据**给出的证据**；如需根据实验供气设定值判断“有无释放/是否仅乙烯”，应作一个独立的**实验程序事实表**，不能将该隐蔽信息用于主审阅意见的对错判定。

审阅问题不使用 L 数字或旧规则措辞，且允许不确定。固定表单列：

| 字段 | 填法 |
| --- | --- |
| `reviewer_id`, `case_id`, `version` | 预先匿名编码、不可事后改 ID；记录表单版本 |
| `action` | `继续观察` / `人工核验` / `优先处置` / `证据不足，先核查信号/配对`；这些是**新表述**，不是预先对齐的 L0—L3 |
| `why` | ≤2 句事实依据；选择气体变化/人员位置/异常配对/证据不足等可多选原因 |
| `confidence` | 低/中/高；不确定可选“证据不足”，不得强制填四级 |
| `reviewed_at`, `prior_s1_exposure` | 完成时间、是否先前见过本项目规则；后者影响盲评资格 |

审阅者彼此单独提交，由保管者在**全部提交之后**一次性解封；事前不展示 S1 分支和相互答案。不要求审阅者证实“真实焦化园区风险”，也不能把物理教师单独意见写作生产安全专家共识。有第二名独立审阅者时记录原始意见分歧，模型在二者不同意见上的行为单列；不经讨论就强行“仲裁”出真值。

## 5. 待冻结的模型与比较方法

固定 S1 原实现：[场景脚本](../scripts/run_stage6_s1_a.py)和[原冻结配置](../configs/stage6_s1_fixed_a.json)；为适配新轨迹的输入解析可新增**只读包装器**，不得根据本轮审阅结果调气体阈值、空间缓冲、连续时间或处置矩阵。任何实现调整都需登记差异并另列，原有 S1 不作事后优化。所有方法都应看到同一模拟窗口且不读取实验供气文件名。

| 比较对象 | 定义与目的 | 输出缺陷须明示 |
| --- | --- | --- |
| 气体单路 | M1 冻结气体事件＋独立事件保留；只报告气体侧提示，**没有人员优先级** | 与多源处置等级不是相同的预测任务，不能简单计算“四级准确率” |
| 人员单路 | P 区域和质量状态，不接收气体结果 | 区域是模拟几何；无法表示气体危险 |
| 简单 OR/AND | 事前给定事件布尔条件，在有效配对时输出是否联合提示；`unknown` 作为单独状态，不能暗中视为零 | 是**二值**对照，不得为公平起见把 S1 四级强行折成任意有利类别 |
| 原 S1 | 完整的 L0—L3＋证据质量及各单路事件 | 它是被审阅的方法；不能用旧 L 矩阵给自身造参照答案 |

**主读数：**按 24 个 `case_id` 列模型输出、每位审阅者的原始行动和解释，逐例标出一致/分歧与证据不足。需要一个合并比较时，先在**揭晓答案前**提交从模型输出到三种行动＋证据不足的映射表；它会压缩 S1 的四级信息，且未必存在单值映射，故若语义不能无歧义对齐，应只报告逐例解释和二值的“是否建议升级人工核验”对应关系。两名审阅者都在时可报告二者原始一致数/24；只有一名时不报告评审间一致性。单路与 OR/AND 仅在双方输出的**同一处置问题**上比较，不宣称它们“预测四级风险较差”。同时统计失配/缺测是否明确保留为不可配对、预释放窗口误触发情况，但后者只有短窗口，非长期假警率。

**停止/降级：**审阅者若事先掌握旧矩阵、评分后修改案例/映射、未保存独立提交底稿，或大多数案例存在不可消解的审阅语义分歧，就只保留为探索性方法检视。若专家依据气体物理工况指出候选控制区无法代表暴露，应报告无效设定并停止对联合处置有效性的推断。无论结果如何，不推断焦化现场事故效果。

## 6. 执行和证据保存顺序

1. 项目组确认**审阅者来源和资格**、可接受的审阅任务；之后据此敲定表单措辞、24 例配额和窗口的冻结配置，并在看新模型输出之前提交 Git。
2. 用独立程序生成匿名案例表、制作同格式审阅包；登记 UCI 309 原归档、抽样种子、匿名映射、模拟轨迹、图片和代码的哈希。实际运行与评分单独保存可复算结果；不将 309 原始文件或审阅者身份放公开 Git。
3. 独立收回意见后锁定原始答案；再由另一人打开模型输出与 322 干扰诊断，按事先确定的映射生成逐例比较。把不同来源按不同表/图展示，异常例逐个报告。
4. 更新[主张账本](../registries/claim_ledger.csv)、图表登记及 T1-A 提纲；如审阅者资格或数据质量未过门槛，在论文中只写探索性分级示例，禁止写“真实风险准确率”。
