# 阶段 7A：UCI 322 与 SB112 分离验证的实验协议（待批准）

拟稿：2026-09-25。项目组选择[阶段 E1 方案 A](stage7-e1-external-data-audit.md)：以 UCI 322 检查气体设定变化后的实验室响应，用 SB112 检查**另一套装置**在未人工触发运行时的报警。本文及[机器可读候选参数](../configs/stage7_a_protocol_candidate.json)仅供批准前审查；**尚未冻结、未运行模型、未看到新性能数值**。旧 309／487／S1 结果已用过的数据不能称为新盲测；新实验不能拼入其结果表的分母。

## 1. 两个不同的问题与独立性单位

| 数据 | 这里唯一要回答的问题 | 实验单位及不能声称的结论 |
| --- | --- | --- |
| [UCI 322](https://archive.ics.uci.edu/dataset/322/gas+sensor+array+under+dynamic+gas+mixtures) | 基于气体传感器、**不使用设定值和时钟作推理输入**时，能否在保留的连续时段识别目标气设定由 0 变为正后的传感器响应；在“双气均零设定”区段触发多少次？ | **乙烯＋CO、乙烯＋甲烷各一条完整实验**，一次实验内有相关的多段变化。可报告按段计的探索性指标，不能把窗口或暴露段当数十次独立试验，更不能把甲烷和 CO 当同期同时泄漏。设定值是气源指令，非传感器口实测浓度或事故真值。 |
| [SB112](https://zenodo.org/records/6616632) | 分别在 CO、CNG、LPG、烟雾四个**本机通道**的无人工触发记录中，既定且因果的报警规则产生多少个报警事件／每个实际有记录的小时？ | 一台智慧楼宇设备的几段运行日，不代表独立企业、独立装置或焦化管廊；没有按秒的正例起点。03-11 的人工刺激仅可画时间曲线，不能评分事故检出率／提前量。 |

气体预警是“在发生暴露后尽快检出”的候选方法，不是泄漏发生前预知。D435、Jetson 都仍是拟部署接口，SB112 烟雾传感器数据不能充当视觉遮挡模型证据。与 309 同步的人位置只有原 S1 仿真轨迹，不与这两组数据构成新的真实同期联合样本。

## 2. UCI 322：分割与在线可用信息

归档 ZIP SHA-256：`8b6323b801363e11343ba1a5a7718e76666b715e753b3a40dbdfd1838d953fe7`；两个文件分别处理，每个参数只允许由其**本文件训练块**估计，不能跨 CO／甲烷直接移植电压阈值。依据先前**仅看设定值、不看模型结果**的[源审计](../results/stage7_e1/uci322_source_audit.json)，提议对两个文件使用相同的绝对时刻：训练 `[3000,12000)` s，验证 `[12300,24000)` s，最终保留 `[24300,39000)` s；相邻块间各隔离 300 s，开头 3000 s 和末尾 39000 s 后不参与主要评分。这是**同一实验内未来时段留出**，不构成跨实验泛化。绝对时间切分使用时间列建清单，**不能把时间列、块编号或时刻的模值交给检测器**。

在拟评分的条件“前一个两气均为零设定的连续段至少 60 s、随后目标气正设定至少 60 s、前驱双零段完全位于本块内，且完整后 60 s 评分窗落在同块内”下，只读审计发现：CO 训练／验证／测试块约为 **5／7／14 次**，甲烷约为 **7／15／13 次**。这是**暴露候选次数，不是已经检出的次数**。120 s 双零阴性保护后，CO 三块约为 290／1472／894 s，甲烷约为 411／1206／1669 s；训练时较宽的 60 s 双零段约为 CO 669 s、甲烷 874 s。这些是原始设定值的时间重叠估算，正式处理须逐一核对有效采样秒窗。候选计数用于确保留出块可评分，不能按这些数量挑选算法后再将测试当盲测。若实现前发现上述资格计算遗漏或边界错误，应在运行检测器之前修订协议、记录版本与原因；不得用结果来修改资格。

- 原始两位小数时间戳在同秒内存在重复；用 `[n,n+1)` 内传感器各通道的**中位数**生成 1 s 完成窗，只在右端 `n+1` s 输出。窗口无有效数据、值不可解析或时间倒退时记 `unknown` 并中断持续证据；禁止未来值填补或跨 300 s 隔离带延续状态。16 通道保留原顺序，不能因某通道在测试表现差而剔除。开始前检查每块的可用窗、重复戳、非有限值和明显饱和；新排除规则需先修订协议。
- 标签仅供训练／验证选参及**离线评分**，禁止出现在在线推理接口。目标气设定由 `0` 转为 `>0`，且之前至少连续 60 s 的**目标气与乙烯均为零设定、这段历史完全位于同一时间块内**时，才有一个合格的评分起点 `t0`；要求目标气正设定至少 60 s，`[t0,t0+60)` 全在本块。`target=0, ethylene>0` 不计清洁阴性；任意气源零设定不等于管内已洗净。
- 保守阴性评分区段：两种气源设定均为零，且**从本块起点开始计算**已经连续满足 **120 s**；端点按秒窗落入，下一次开始供气前停止计时。训练基线与阈值估计允许使用至少连续 **60 s** 的双零段，以免早期 CO 训练块阴性不足，评分阴性始终用 120 s；二者分开列时长与排除秒数。两种设定只作为离线段标注，**测试中不依据标签重置推理器**。零设定区段的残留气与漂移可能产生报警，故称“实验程序阴性代理”，不是实测无气真值。
- 用训练块阴性时段确定每通道中心、稳健尺度（中位数、`1.4826 × MAD`；尺度为零先记质量异常）；阳性评分的响应只看传感器值。主比较为 **B0 单通道偏离量**与 **B1 十六通道偏离量的中位数**，两者共用同一处理及固定的连续 3 个有效秒窗才形成报警。B0 通道只能按训练数据事先选定并记录；提议按训练区段背景偏离后的设定变化响应的中位差最大、同分取原通道编号最小，验证／测试不换通道。受控气室可以先看偏离绝对值；不能从绝对偏离推断是哪种气体。
- 每种方法只用**训练块连续双零至少 60 s 的分数**按线性插值计算 0.99 分位作主阈值，0.995 分位只作预列敏感性；不因验证或测试结果更换主阈值。每个文件分别估计两种方法的阈值。全块持续回放（训练参数不在验证／测试改变），报警事件首次由非报警进入报警时记一次；短暂清除后再次进入要列数但不能作为新的独立实验。若 B0／B1 的训练用有效秒数不足 300 s、任一方法没有有限分位数或训练／验证均无合格正例，则停止其定量比较并报告不能实施。**现有 CO 训练块 120 s 洗净口径仅约 290 s，故必须明确利用 60 s 口径训练并写出不稳的分位估计风险。**

主表按气体文件**分别**给出：训练、验证、测试有效正例数和阴性小时；测试正例中在起点后 **60 s** 内首次新发报警的数量／分母、首次触发延迟的逐事件分布与未检出数；测试双零阴性区段的报警事件数／有效小时。跨 `t0` 持续的报警、`t0` 前开始累积而 `t0` 后才满足三窗的报警，单列“提前存在的背景证据”，**不能计为释放后新检出**；无报警的事件不填 60 s 延迟。阈值不根据“想要更好看”的误报率重选。正例若同一长源暴露反复起落，按设定由零到正的资格规则只计一次起点；所有秒窗留在原试验时间轴，不拼接造成虚假连续性。

**时钟捷径必报检查：**给出一个只根据训练时刻/重复预设程序建立的“时钟预测”诊断输出，标注它使用了**禁用的标签信息**，只用于显示资料可被程序猜中，绝不充当可部署报警器；另用训练阶段冻结的传感器常值替代输入做负控（明确标仿真）。不能把固定图案重复出现的测试片段说成未知事故泛化；如果传感器破坏后依旧在设定起点附近表现相同、两个真实气体文件在不同时间块表现极不稳定，停止“动态预警优越”论断。不会在本阶段训练神经网络、搜索数十种阈值。

## 3. SB112：本机阴性分割与报警时间分母

四个原始 XLSX 均已按 Zenodo 文件 MD5 检验，时间戳示例带 `+02:00` 时区；依各自原始时间戳日历日：**03-08 训练基线、03-09 验证说明、03-10 保留最终阴性日、03-11 只作刺激过程定性图**。四路分别读各自的 `time,data_type,unit,data_value`，同一天不同通道**不按邻近时刻合并成同期多源事故样本**。三天中 03-09 早间存在开机缺口；不以日期“24 小时”直接作分母。

每路以 03-08 有效值的训练中位数和上侧分位数构成**本机、单变量上升报警**：主阈值为该日 0.99 分位，敏感性为 0.995 分位（两者与设备单位一起记）；主规则要求连续 **2 个有数据的观测**超阈值且两次相邻间隔不超过 60 s，敏感性为连续 3 个。值等于阈值不触发。此处 quantile 是背景分布研究参数，**不是 CO／LPG 等法律或工业安全限值**；不声称能抓住 03-11 的刺激。若基线常数、过多缺测、格式不一致，先报告不能计算，不靠测试日重新标定。验证日只用于检查缺失、时钟、基线漂移及规则是否失效，**不按验证日误报数挑最沉默的规则**。

在 03-09 与 03-10 各自独立计算观测覆盖时间：按相邻两个有效且时间严格递增的观测之差累计，**仅在 `0 < Δt ≤ 60 s` 时把 `Δt` 计入分母**；更长间断既不计小时，也使连续超阈值状态和正在计数的报警事件结束。报警从非报警转为报警记一次；若**同一无断档运行片段内**的再次触发与上次清除不足 300 s，合并为一个事件用于主“事件／覆盖小时”，同时留原始触发次数，避免反复抖动刷高事件数。复测区间相距 >60 s 时记录新运行片段，从零累积且**禁止跨片段合并**。有效覆盖小时为零则不计算率。为看基线漂移，按日列出每通道训练／验证／测试的中位数与样本覆盖，不将 4 路计数直接加总估计“独立事故率”。

主表为每个通道分别列验证日和 03-10 保留日的**有效覆盖小时、报警事件数、事件／覆盖小时、首次报警时刻及阈值敏感性**；如有独立运行段，可列分段触发情况，不以 20 s 采样点做独立统计置信区间。03-11 只绘出带时间轴的原值／已冻结阈值，注明人工刺激范围以**整天**为弱标签；没有精确点火时间，不能计算检测时延、召回、准确率或事故前预警。若训练日和保留日基线明显漂移，报告固定本机阈值局限，不“回头补校准”测试日。

## 4. 数据隔离、验收记录与停止线

1. 先通过审核这一稿并另存**批准后的冻结配置 SHA-256 与 Git 提交**；再实现读取／阈值／评分、做针对时间边界及状态重置的必要测试。运行程序输出原 ZIP／XLSX 的哈希、协议版本、命令、按块清单、逐事件和逐通道结果；绘图从正式结果表读取，登记证据。任何改动评分规则均版本化，禁止覆写历史实验结果。
2. 首次运行前写下可判定的缺失／异常处理；对验证数据只做一次方法检查，**最终测试一次**。若协议执行过程中发现源标签或列读错，停止、修复并留勘误；若只是结果不好，不动测试规则或删样本。已经浏览过数据源的元信息和设定值计数，所以这是**预先规定的留出分析**，不称未知数据集盲测。
3. 无论数字好坏，UCI 322 的“设定值变正后的检出”与 SB112 的“无人工触发背景报警”只允许各自成立；**不能相除或加权产生一个综合准确率，也不能把这两项评分直接变成 S1 四级真实风险 F1**。若要在阶段 8 映射到系统拟部署，须明确新设备的校准、传感器覆盖和真实人员位置均待验证。
