# 新数据核验：TADI 受控甲烷释放（暂不纳入主实验）

核查日期：2026-09-27。本报告只读审计来源和原文件，**没有训练模型、解锁 B2/J1 选择期或改写论文结论**。项目组已表示：若数据确实有用而自动下载失败，可由成员手动下载；本次九个文件已由助手成功下载，无需成员操作。

## 先问数据能验证什么

当前 B2 煤矿数据按目标传感器越限定义标签，没有独立事故发生真值；其 J1 候选还未获准运行选择期。因此不能再把它作为论文有效性的主证据。寻找新数据时，必须明确评价目标并具有独立参照。

TADI 数据来自法国 TotalEnergies 的受控甲烷释放活动，而不是山西焦化厂。六个低成本传感器日志同时列出 MOX 电压与高精度仪器的 `CH4` 参考浓度（ppm）。它能回答一个具体且可测的问题：**低成本多传感器读数在不同释放试次、不同仪器/位置及缺测条件下，能否重建同期参考浓度，并给出可靠的不确定性？**参考浓度不能作为模型输入，只能作为拟合目标或留出检验参照。已有原论文比较过 MLP 与二次多项式，后续若使用必须与原作者方法比较并核对有无真正的新问题。

它**不能**直接检验危险浓度下的安全分级、事故提前预警、泄漏起点识别的长时误报、焦化现场泛化、真实人员与气体同期融合。观测的 ppm 增量接近环境背景至几十 ppm，不得套用可燃气体 LEL 报警阈值。Bonn 人员轨迹仅能另作模块实验，拼接时须标明仿真。

## 来源与原件

- 原作者资料：[Zenodo 记录](https://zenodo.org/records/8399829)，DOI `10.5281/zenodo.8399829`；对应论文 [Atmospheric Measurement Techniques 17 (2024), 4257–4290](https://doi.org/10.5194/amt-17-4257-2024)。记录 API `https://zenodo.org/api/records/8399829` 的许可字段为 `cc-by-4.0`。九个原数据文件合计 4,687,937 字节，页面约 4.7 MB。
- 已下载至 Git 忽略目录 `data/raw/tadi_2019/`，不随仓库发布原件。下载文件：`Logger_A.csv`、`Logger_C.csv`、`Logger_D.csv`、`Logger_E.csv`、`Logger_F.csv`、`Logger_H.csv`、`Loggers_COLUMNS.txt`、`sonic3d_anemometer.csv`、`sonic3d_anemometer_COLUMNS.txt`。原始文件链接形式为 `https://zenodo.org/records/8399829/files/文件名?download=1`，目前无需组员下载。
- 六份 Logger 合计 **38,826 行**；33 个不同的 `Release` 编号是 33 次活动在多个记录器上的重复观察，**不是 38,826 次泄漏**。实际行数分别为 A 7431、C 5742、D 2542、E 7126、F 7110、H 8875；风速仪文件另有 1782 行。每份日志包含时间、`CH4` 参考浓度、MOX 电压、部分温湿度/气压和 `Release`；不同记录器的环境列不完全相同。
- `Release` 在每行都是 1–33 中的某个正整数，**没有 0/无释放标签**。各日志的时间区间相隔较大，文件是所选试次的观测片段，不能把相邻两行的跨试次间隔当作完整阴性时长，也不能把某试次首行直接当作阀门真实开启时刻。部分温湿度记录含 `-9999.0` 缺失哨兵。论文指出低成本电压与参考浓度对齐需要处理管路与设备的约 2–3 分钟时间偏移，且低成本传感器在高峰值会饱和；开发协议前须检查原文件是否已经对齐，避免再对齐一次或使用未来信息。

## 与论文的决定

**可保留为“甲烷浓度重建/传感器可靠性”的可用候选，不认定为泄漏预警主数据。**下一步只宜做预注册前的质量分析：按 `Release` 分组核查参考值范围、缺失、同一时间多记录器配对率、试次之间的分布与原论文已有基线；如果看不出比原论文更清楚的增量，停止这条候选。已经完成的 B2 结果如实写为失败/适用性边界，不通过换数据掩盖。

同时筛过一份 [ADAM 甲烷数据](https://zenodo.org/records/21892655)：716 kB 工作簿、2000 个“事件”行，`Ground_Truth_Label` 按参考浓度导出，属于人为控制暴露试次的窗口/记录标签，不是 2000 次独立泄漏，也不能用于推算事故起点和长时连续误报。本次不建议纳入。

本次只是来源审计，没有决定最终论文题目或模型；若要主张“释放事件检出和长期阴性误报”，仍须找到独立阀门起止记录与连续背景，或将论文问题收缩为参考浓度重建与模块级验证。
