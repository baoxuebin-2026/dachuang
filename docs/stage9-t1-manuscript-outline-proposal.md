# 阶段 9：T1 论文提纲与图表证据方案（正文主次 A 已确定）

日期：2026-09-25（北京时间）。项目组已确认[修订后的 T1 路线](stage8-n1-system-evidence-map.md)：**原项目名称不变**，论文在申报系统框架内研究方法，分模块展示公开数据实验和明确标注的仿真。本文件只确定可写内容和证据位置，**不是论文正文，也不表示论文已完成、投稿或发表**。既有[申报承诺与完成情况](commitments.md)仍须在中期及结题时逐项说明。

## 1. 拟议研究主张与题目

暂用论文题目：**《面向焦化园区的多源感知与分级预警方法研究：分模块公开数据实验与场景仿真》**。这是方法适用的**拟议场景**，不是焦化企业现场实验标题。核心问题：当气体变化证据和人员位置证据来自不同来源、存在质量与时空不确定性时，如何设计能追溯来源、保留缺测状态的分级处置流程，并分别验证各模块与仿真规则的行为？

拟议贡献应收窄为：① 定义气体、视觉、仿真人员状态的来源及质量接口；② 在实验室气体数据和室内 RGB-D 数据上分别检验局部功能；③ 在**人为设定同钟、同区和人员轨迹**的重放里检查条件处置、错误区域及缺测传播。③ 是软件规则与场景仿真的可复现检查，不能作为真实联合感知的外部效度证明。现有实验未给出事故发生前的独立事件真值，因此正文不主张事故预测提前量或真实风险分级准确率。
