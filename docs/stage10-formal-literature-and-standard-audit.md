## 4. 引用与措辞冻结

1. “释放后 60 s 内检出”只指 UCI 309 的程序供气开始之后；不写“事故前 60 s 预警”。
2. “三维视觉”在正文中具体拆为 RGB-D 输入、二维框、ROI 深度可用性和相机相对虚拟区域；不写“完成人体三维定位精度验证”。
3. “多源交叉验证”写成拟部署目标；已做结果称“实验气体证据＋仿真人员状态的规则重放”。
4. “固定阈值跨日期不稳定”由 METEC 按日期留一诊断支持；不把 METEC 阈值迁移到 UCI 或拟部署设备。
5. 标准只负责界定应用背景和未来仪器要求；算法阈值、区域边界和 L0—L3 均不得冒充标准限值或标准分级。
