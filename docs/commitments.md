# 申报书承诺与实际证据对照（持续更新）

正式项目名称：面向山西省焦化园区的智能安全预警系统研究。周期：2026 年 5 月至 2028 年 5 月。此表用于中期检查与结题复核；“计划”不等于“完成”。

| 申报书内容 | 当前状态 | 后续需补的证据／需解释的差异 |
| --- | --- | --- |
| 气体异常与环境信息协同 | 309 气体检测探索实验、487 独立 CO 校准实验；322 两条气室时序及 SB112 本机背景报警独立验证；**这些数据互不同步**。阶段 7B 确认 322 的 B1 对仅乙烯气源变化同样报警，属于泛气体响应异常证据 | 322 仍仅两条程序化长运行，合格双零阴性短；SB112 另一设备且无逐秒阳性；不能把 B1 写作 CO／甲烷气种专一检测，亦不能将多项实验拼成山西焦化企业数据 |
| 人员误入／越界、三维距离 | 已运行明确标注来源的二维仿真人员轨迹、控制区关系及参数敏感性；已取得波恩大学两条 RGB-D 序列，完成 115 帧独立人工标注与[固定预训练模型的室内二维人员框验证](stage8-v1a-a2-2d-detector-results.md)；另完成[第一条序列的深度 ROI 可用性与候选门槛敏感性分析](stage8-v1a-a2-depth-gate-dev-sensitivity.md)；**尚无独立人体距离真值或实际越界实验** | 室内二维框和 ROI 深度不能当作焦化现场人员识别、测距精度；危险区边界与定位误差仍属假设，没有使用过 D435，不能声称 D435 采集或测距验证 |
| 视觉＋气体时空关联 | 已完成“实验室气体证据＋仿真位置”的受控场景重放；**未获得真实同期视觉数据** | 人为设定的时空配对只验证规则一致性和缺测处理；不能当作现场多源融合准确率或真实事故提前量 |
| 烟雾遮挡检测 | 未完成 | 后续补独立的小规模验证，或在结题时如实说明范围调整；**阶段 6／10 提醒** |
| 液体泄漏／积液识别 | 未完成 | 同上；**阶段 6／10 提醒** |
| 车辆违规、人员操作违规、粉尘 | 未完成 | 属申报书点位示例，逐项核对最后成果；不得以框架图充当检测结果 |
| 分级预警和提前预警 | 已执行 S1 的仿真分级重放与未知输入反例；实际事故提前预警未验证 | 风险等级是研究内规则，不能拿来自己验证“事故 F1”；释放之后的检出延迟不能称为事故发生前预警 |
| Intel RealSense D435、NVIDIA Jetson Orin Nano 及现场传感器 | **从未使用；只属于拟部署架构** | 仅阐述接口、位置与可行性；无设备采集和 Jetson 延迟、功耗等实测结论；**阶段 8／10 提醒** |
| 学术研究论文“撰写并发表” | 未完成 | 完成真实实验后撰稿；投稿、录用、发表分别记载，不得混称；**阶段 9／10 提醒** |

本项目已确认不制作完整实体样机。正式申报书写有“选用设备并接入传感器”及多类场景模型；项目实施范围调整应与指导教师和学校管理方核对，不能单凭论文措辞消除原承诺。

2026-09-25 项目组选择 B：以“泛气体响应异常的独立实验室证据＋仿真人员区域处置”为主线。设备及未完成视觉任务的[逐项证据核对和下一步验证备选](stage8-scope-and-evidence-options.md)已形成；项目组随后选择 V1、A，项目组要求更换来源后已取得并审查波恩大学[两条人员序列](stage8-v1a-two-sequence-protocol-proposal.md)。项目组选择 A2，现已有 115 帧[抽样与人工标注工具](stage8-v1a-a2-annotation-kit.md)及[115 帧人员二维框实测结果](stage8-v1a-a2-2d-detector-results.md)；人员测距、固定危险区域越界和焦化现场验证仍未完成。
