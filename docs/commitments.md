# 申报书承诺与实际证据对照（持续更新）

正式项目名称：面向山西省焦化园区的智能安全预警系统研究。周期：2026 年 5 月至 2028 年 5 月。此表用于中期检查与结题复核；“计划”不等于“完成”。

| 申报书内容 | 当前状态 | 后续需补的证据／需解释的差异 |
| --- | --- | --- |
| 气体异常与环境信息协同 | 309 气体检测探索实验、487 独立 CO 校准实验已完成；两套数据非同步、不同装置 | 309 缺长时纯阴性与新释放时刻的独立测试；不能把两套实验拼成同一现场，也不能写成山西焦化企业数据 |
| 人员误入／越界、三维距离 | 已提出阶段 6 场景设计，未生成或运行轨迹 | 人员位置、危险区边界与定位误差设定的依据；没有使用过 D435，不能声称 D435 采集或测距验证 |
| 视觉＋气体时空关联 | 已提出仿真配对契约，未验证 | 说明人为设定的联合场景与真实同步观测的区别；对照单源时只能评价逻辑性质，不能自造事故标签证明准确率 |
| 烟雾遮挡检测 | 未完成 | 后续补独立的小规模验证，或在结题时如实说明范围调整；**阶段 6／10 提醒** |
| 液体泄漏／积液识别 | 未完成 | 同上；**阶段 6／10 提醒** |
| 车辆违规、人员操作违规、粉尘 | 未完成 | 属申报书点位示例，逐项核对最后成果；不得以框架图充当检测结果 |
| 分级预警和提前预警 | 已批准 S1 仿真处置等级，尚未运行人员联合情境；实际事故提前预警未验证 | 风险等级是研究内规则，不能拿来自己验证“事故 F1”；释放之后的检出延迟不能称为事故发生前预警 |
| Intel RealSense D435、NVIDIA Jetson Orin Nano 及现场传感器 | **从未使用；只属于拟部署架构** | 仅阐述接口、位置与可行性；无设备采集和 Jetson 延迟、功耗等实测结论；**阶段 8／10 提醒** |
| 学术研究论文“撰写并发表” | 未完成 | 完成真实实验后撰稿；投稿、录用、发表分别记载，不得混称；**阶段 9／10 提醒** |

本项目已确认不制作完整实体样机。正式申报书写有“选用设备并接入传感器”及多类场景模型；项目实施范围调整应与指导教师和学校管理方核对，不能单凭论文措辞消除原承诺。
